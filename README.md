# Jigsaw Garage

เกมจิ๊กซอว์สำหรับเล่นบนเว็บเบราว์เซอร์ ใช้ภาพ `car.jpg` และเขียนด้วย HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## วิธีเล่น

เปิด `index.html` ด้วยเว็บเบราว์เซอร์บน PC เลือกระดับ แล้วลากชิ้นส่วนจากถาดไปวางบนกระดาน กระดานจะซ่อนภาพต้นฉบับ ชิ้นส่วนจะล็อกเมื่อวางใกล้ตำแหน่งที่ถูกต้อง

มี 4 ระดับ: ง่าย 12 ชิ้น, กลาง 24 ชิ้น, ยาก 60 ชิ้น และเป็นไปไม่ได้ 150 ชิ้น

## โหมด Auto

- **Auto: ด่านนี้** เล่นด่านที่เลือกให้จบโดยอัตโนมัติ
- **Auto: ทุกด่าน** เล่นครบทั้ง 4 ระดับตามลำดับ โดยแสดงการเคลื่อนชิ้นส่วนทีละชิ้น
- กด **หยุด Auto** เพื่อหยุดและเก็บความคืบหน้าปัจจุบันไว้
- เอฟเฟกต์เรืองแสงและเสียงเบา ๆ จะเล่นเมื่อหยิบหรือวางชิ้นส่วน
- กด **♫ เพลง: ปิด** เพื่อเปิดเพลงบรรเลงชิล ๆ ที่สร้างจากเสียงสังเคราะห์ในเกม เพลงจะไม่เล่นเองจนกว่าจะกดปุ่ม

ไฟล์ `GAME_PLAN.md` มีแผนและเกณฑ์ตรวจรับของเกม
